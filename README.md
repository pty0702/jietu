# QuickSnap — 极简截图工具

单文件 C# 截图工具，编译后为一个无依赖的 `QuickSnap.exe`（用 Windows 自带的 .NET Framework 编译器编译，不需要安装任何运行时）。

## 功能

- **托盘常驻**：启动后缩到任务栏托盘（相机图标），单实例运行
- **Alt+A** 全局热键截图（也可双击托盘图标 / 托盘菜单触发）
- 全屏变暗，**鼠标拖拽框选**区域，实时显示选区尺寸
- 松开鼠标 → **默认复制到剪贴板**（同时含 DIB + PNG 格式，微信/Word/QQ 等直接粘贴）
- **可选保存**：
  - 点击复制成功后的气泡通知 → 弹出另存为对话框（默认存到"图片"文件夹）
  - 托盘菜单「保存上次截图…」
  - 托盘菜单勾选「截图后自动保存到 图片\ScreenShots」→ 每次截图自动存 PNG
- **Esc 或右键** 取消截图

## 使用

```
build.bat        # 编译
QuickSnap.exe    # 运行（托盘图标出现即生效）
```

开机自启：`Win+R` 输入 `shell:startup`，把 QuickSnap.exe 的快捷方式放进去。

## 限制

- 多显示器支持（整个虚拟桌面截图），但在不同 DPI 缩放率的显示器混用场景下按系统级 DPI 处理，混合缩放时坐标可能有偏差
- Alt+A 被其他软件占用时启动会弹气泡提示，可改代码里的 `MOD_ALT` / `'Z'`（如 `MOD_CONTROL | MOD_ALT` + `'Z'`）
